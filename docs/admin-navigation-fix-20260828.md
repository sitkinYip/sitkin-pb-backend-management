## 发现

用户报告首次进入 404、退出后出现旧邮箱登录表单，页面地址为 https://vae.sitkin.top/login。实际 HTTP 检查根路径、/login、/players、/index.html 均返回新包 index-rMCFwKOR.js，Cache-Control: no-cache；该包含新版管理员账号表单，不含旧邮箱表单文本。因此旧页面的来源尚未完全确认，可能是既有页面/缓存；已请用户打开带 release 参数的入口核对，不把推测当结论。

已确认 Refine useLogin 优先采用查询参数 to，而非 authProvider.redirectTo；旧链接中的 /levels 等路径在新路由下会进入 404。

## 修复

- 明确 /players 为登录成功、根路径和已登录登录页的默认目标，与菜单第一项用户管理一致。
- 过期/未知业务路由回到默认首页。
- 在挂载登录表单前清理过期、不安全和重复的 to 参数；只保留当前菜单的有效本地路径，防止外站回跳。
- 登录只接受管理员 account，不回退旧邮箱字段；退出返回统一 /login。
- 提取可测试的认证工厂和路由策略，不更改布局及样式。
