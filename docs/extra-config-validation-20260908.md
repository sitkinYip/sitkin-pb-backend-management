## 实现范围

- 专属头衔按用户＋已有成长等级覆盖名称；经验阈值、等级顺序、入场条件和结算继续使用原规则。支持未来等级预设、撤销、审计、版本冲突和幂等重试。
- 增加三个空私有集合：`game_player_level_titles`、`game_extra_definitions`、`game_extra_configs`。原有集合没有增加列、改结构或回填记录；通用扩展值集中存储，避免在各业务表重复增加 JSON 列。
- 管理端支持字段结构定义、动态输入、公共／当前全部／指定用户下发、七种目标范围、影响预览、版本冲突、批次撤销、分页与生效来源查看。
- 玩家协议保留经过边界校验的 extra 命名空间；资料、场次、已解锁关卡接入通用文本展示。仅管理可见、其他用户及未解锁题目配置不会进入玩家响应。
- 定义兼容性、容量限制、失效配置隔离与请求内批量读取已实现。此机制用于扩展数据传输，新的业务行为仍需相应代码。

PB_DOCKER_IMAGE=questions-pocketbase:extra-config-test-20260908 node backend/scripts/verify-image.mjs
