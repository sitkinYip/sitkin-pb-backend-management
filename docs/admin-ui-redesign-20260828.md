# 管理后台 UI 与运营指引改造

本文是 2026-08-28 的实现与验收快照。后续管理页面、组件、PC / 移动端响应式和视觉验收统一遵循 [管理后台 UI 工程与样式规范](admin-ui-engineering-standards.md)，不要把本文当成当前完整规范。

## 范围

仅调整管理前端，不修改 PocketBase 数据结构、接口、奖励 / 下线规则、答题页或线上数据。未执行提交、推送、生产部署或真实 Alist 上传。

沿用 Ant Design 与 Refine，在现有页面上统一工作台样式，而非替换组件库或重写业务流程。

## 主要变化

- 全部 12 个管理模块统一页头、操作区、内容容器与配置指引。浅色 / 深色外观共用主题和布局规则。
- 表单增加示例占位、字段说明和补充气泡；保留 6 处富文本语法帮助。特别说明题目引用锁定、场次不可恢复下线、重新下发的重复奖励风险、累计经验和私有取件码。
- 桌面双列表单、手机单列表单；关卡惩罚和等级编辑行改用网格。抽屉保存操作移到底部，保持可访问。
- 表格使用明确列宽与表内横向滚动，按钮和短状态不拆成逐字换行。长标题仍可完整换行阅读。
- 题库和玩家列表增加搜索；资源库连接说明、剧情类型、答题结果与审计操作改用易懂的中文。
- 手机导航进入固定页头，去掉原悬浮导航入口；登录页使用 border-box 与动态视口高度，避免全屏高度叠加 padding 导致滚动。
- 手机日期 / 时间弹层改为纵向布局，时分秒列可滚动；小高度视口允许弹层内部滚动。
- 修正只读场次中“上移”按钮显式 disabled 覆盖表单只读状态的视觉问题。

## 维护位置

- `src/styles/admin.css`：主题变量、工作台与响应式规则。
- `src/contexts/color-mode/index.tsx`：Ant Design 主题配置。
- `src/game/ui.tsx`：PageCard、Field、AdminTable、EditorDrawer。
- `src/game/guidance.ts`：页面与字段运营说明；规则变更时需同步复核文案。
- `src/game/display-labels.ts`：审计显示文案，未知新类型保留原始值。

Field 仍将单个输入组件直接交给 Form.Item；不包裹输入本身、不转换输入值。场次四个标签页继续保留 forceRender，未打开的页签配置也会保存。

## 验证

使用临时本地 PocketBase 演示容器，前端显式指定本机 API。测试数据与生产隔离。

- `pnpm test:admin`：33 项通过（原有 25 项 + 8 项 UI 回归）。
- `pnpm check:contracts --admin-only`：通过。
- `pnpm build`、`git diff --check`：通过。构建仍有单包大于 500 kB 的体积提示，不影响构建；本次未扩展到分包优化。
- 12 个模块逐页检查 320×667、1440×900：文档宽度均等于视口宽度；表格宽于容器时仅表内滚动。配置页内容较长时保留正常纵向滚动。
- 登录页在 320×667、375×667、390×844、768×900、1440×900 下文档尺寸与视口一致；320×480 下内容高 567px，允许正常纵向滚动，不截断登录入口。
- 320px 场次抽屉宽度为 320px；基础字段与小关卡网格无横向溢出。
- 实际打开手机日期弹层，确认日历和时间列可同时完整访问。
- 填写测试题目、富文本题面和两行答案 → 保存 → 重新打开，文本与数组内容保持一致。
- 复制演示场次为草稿，仅修改名称后保存；重新查看仍保留 2 个关卡与原发奖规则。
- 检查浅色 / 深色外观、只读表单和移动导航。

验收为浏览器中的响应式视口检查，不等同于 iOS / Android 真机测试；输入法、软键盘和安全区域仍建议发布前用实际手机抽查。

## 本地复验

先按现有本地演示文档启动隔离后端，再显式指定测试 API 启动 Vite，避免默认连接生产服务。开发环境可访问 `/tests/responsive-preview.html`，选择宽高与页面，点击“检查布局”查看尺寸。该 HTML 不在生产构建入口中。

上线仅需按现有管理后台 Actions 流程构建发布；无需迁移数据库或重新部署后端 / 答题页。
