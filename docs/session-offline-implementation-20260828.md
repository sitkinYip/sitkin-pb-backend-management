## 旧归档补齐工具

`backend/scripts/reconcile-closed-sessions.mjs` 默认仅预览，可在旧后端上通过现有目录和下发接口生成清单；不要求先部署新规则才知道会影响谁。

在可信终端通过环境提供 `PB_URL`、`QUESTIONS_ADMIN_ACCOUNT`、`QUESTIONS_ADMIN_PASSWORD`，不得写入仓库、截图或公共日志。远程访问必须 HTTPS 并显式加 `--allow-remote`。

在 `backend/` 下运行：

```sh
# 默认仅预览；远程需另外加 --allow-remote。
node scripts/reconcile-closed-sessions.mjs

# 先预览准确目标，多个目标可重复 --session 参数。
node scripts/reconcile-closed-sessions.mjs --session=SESSION_ID_FROM_PREVIEW

# 必须先获生产处理授权并部署新后端，再执行；没有 apply-all 模式。
node scripts/reconcile-closed-sessions.mjs --session=SESSION_ID_FROM_PREVIEW --apply
```

`SESSION_ID_FROM_PREVIEW` 执行前需换成已核实的真实 ID。脚本拒绝对未归档目标执行补齐、拒绝在旧后端执行 apply；按业务下线逻辑处理，不直接写 SQL。
